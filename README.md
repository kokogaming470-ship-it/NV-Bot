# NV BOT 🤖⛏️

بوت ماين كرافت **Forge 1.20.1** بيتحكم فيه من ديسكورد + لوحة ويب.
الجزء بتاع ديسكورد/الويب/المودات = **Python**، وجزء الدخول للعبة = Node.js صغير (`bridge/bot.js`) لأن مفيش مكتبة بايثون بتدعم Forge 1.20.1.

## المميزات
| الأمر | بيعمل إيه |
|---|---|
| `/join` | يدخل البوت السيرفر ويبعتلك رابط لوحة التحكم |
| `/panel` | رابط لوحة التحكم (مشاهدة حية + تحريك + شات) |
| `/leave` | يطلّع البوت |
| `/watch` | يراقب لاعب معين (بيبصله وبيمشي وراه) |
| `/rotate` | مراقبة دورية: كل لاعب 5 دقايق (تقدر تغيّر الرقم) وبعدين التاني |
| `/skip` | تستثني لاعب من الدورة |
| `/stealth` | Spectator / Creative / شفاف (لازم البوت أوب) |
| `/afk` | حركة عشوائية عشان ميتطردش |
| `/say` | يكتب في الشات |
| `/status` `/players` | حالة البوت واللاعبين |
| `/mods` | رابط تحميل المودات للناس (من غير تحكم) |
| `/replays` | رابط التسجيلات |

**التسجيل:** كل جلسة بتتسجل في `recordings/*.jsonl` (شات، دخول/خروج، موت، ضرب، بلوكات اتكسرت/اتحطت حوالين اللاعب المراقَب، ومكان كل لاعب كل ثانية). صفحة `/replay` بتشغّلها كـ"فيديو" خريطة من فوق مع Timeline وقايمة أحداث تضغط عليها تروح للحظة دي.
> ده مش فيديو mp4 حقيقي (ده محتاج GPU ورندر ثقيل مش هيشتغل على استضافة مجانية)، لكنه بيوريك بالظبط إيه الي حصل ومين كان فين.

## 1) التجهيز
```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y python3 python3-pip python3-venv nodejs npm build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev
# نود 18 أو أحدث (node -v). لو أقدم: https://nodejs.org

cd nv-bot
npm install
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # وعدّل فيه
```

## 2) بوت ديسكورد
1. https://discord.com/developers/applications ← New Application ← Bot ← Reset Token وانسخه في `DISCORD_TOKEN`.
2. OAuth2 → URL Generator: اختار `bot` + `applications.commands` وضيفه لسيرفرك.
3. حط `GUILD_ID` و `ADMIN_IDS` (ايديك) في `.env`.

## 3) ماين كرافت
- اسم البوت **`NV_BOT`** (ماين كرافت مبيقبلش مسافات).
- في كونسول أتيرنوس: `whitelist add NV_BOT` و `op NV_BOT` (الأوب مطلوب للإخفاء بس).
- **الدخول بدون حساب أصلي:** السيرفر لازم يكون **Cracked** (إعداد Aternos: Options → Cracked). لو السيرفر Premium غيّر `MC_AUTH=microsoft` وهيطلب منك تسجل دخول بحساب في أول مرة.
- حط ملفات المودات (.jar) في فولدر `mods/` (بـ `scp` أو FileZilla/WinSCP).

## 4) تشغيل
```bash
python main.py
```
افتح من المتصفح: `http://IP:8080/mods` (صفحة المودات) — ولوحة التحكم الرابط بتاعها بيظهر في `/join`.
افتح البورتات **8080** و **3007** في الـ firewall.
> ⚠️ العرض الحي (3007) مفيهوش باسورد (مشاهدة بس، مفيش تحكم). متفتحوش لحد عايز تخفي الـ IP عنه، أو قيّده بالـ firewall على IP بتاعك.

للتشغيل الدائم: `sudo apt install tmux && tmux new -s nv` وشغّل جواه، أو اعمل systemd service.

## 5) استضافة مجانية بتستحمل (المودات ~1.7GB)
| الاستضافة | رأيي |
|---|---|
| **Oracle Cloud Always Free** (VM ARM: 4 أنوية/24GB رام/200GB تخزين) | ⭐ الأفضل بفرق. مجانية للأبد، تستحمل المودات والبوت بسهولة. محتاج كارد للتسجيل (مبيخصمش). |
| جهازك/لابتوب قديم/Raspberry Pi | ممتاز لو بيفضل شغال. |
| Render / Railway / Koyeb (مجاني) | **مش مناسبين**: بينامو أو تخزينهم مؤقت، والمودات 1.7GB هتضيع. |
| Replit / Glitch | مش مناسبين للحجم ده. |

على Oracle: افتح البورتات من Security List **وكمان** `sudo iptables -I INPUT -p tcp --dport 8080 -j ACCEPT` (ونفس الكلام لـ 3007).

## ملاحظات مهمة (بصراحة)
1. **Forge handshake** مكتوب يدوي لـ 1.20.1 ومقدرتش أجربه على سيرفرك. لو البوت اتطرد بعد الدخول بـ "Incompatible/Mod channel": خلّي `FORGE_DEBUG=1` وابعتلي سطور `forge_raw`/`forge_error` من اللوج وأظبطهالك.
2. **المودات الي بتضيف بلوكات** ممكن تخلي العرض الحي يبان فيه بلوكات ناقصة أو يوقع الرندر. البوت نفسه والتسجيل بيكملوا شغل عادي لأن الأخطاء معمولها catch.
3. **المراقبة بتعتمد على مسافة الرؤية** (حوالي 8–10 chunks): لو اللاعب بعيد البوت مش هيشوفه. لو البوت أوب فعّل `TP_TO_TARGET=1` وهيعمل `/tp` للاعب كل ما يتغير.
4. **أتيرنوس** بيقفل السيرفر لو مفيش لاعبين، والبوت بيعتبر لاعب فبيخليه شغال، لكن أتيرنوس بيمنع الـ AFK bots في شروطه وممكن يطرد الحسابات المشبوهة. على مسؤوليتك.
5. استخدم البوت للمراقبة على سيرفر إنت مسؤول عنه واعلم اللاعبين إن في تسجيل (ممكن تكتب `/say` أو في قواعد السيرفر).
